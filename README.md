# 🎂 Happy Birthday Brother ❤️

A beautiful interactive birthday surprise website created especially for my brother. The project features a cinematic animated background, 3D-style CSS cake, candle-blowing interaction, confetti, birthday message, animated gift box, floating hearts, and background music.

## ✨ Features

* 🎂 3D-style birthday cake
* 🕯️ Interactive candle-blowing animation
* 🎉 Animated confetti celebration
* ✨ Glowing stars and floating particles
* 💖 Animated birthday message
* 💌 Personal brother message
* 🎁 Interactive 3D-style gift box
* 💕 Floating hearts on the final screen
* 🎵 Birthday background music
* 📱 Fully responsive mobile design
* 💻 Works on desktop and mobile browsers
* 🌐 Ready for GitHub Pages hosting

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Animations
* HTML5 Audio

## 🚀 How to Run Locally

1. Download or clone this repository.

2. Open the project folder.

3. Make sure all files are present:

```text
index.html
style.css
script.js
song.mp3
```

4. Open `index.html` in your browser.

5. Click **Start Surprise** and enjoy the birthday animation. 🎉

## 🎵 Adding Your Own Song

Place your MP3 file inside the project folder and rename it:

```text
song.mp3
```

The structure should be:

```text
birthday-brother/
├── index.html
├── style.css
├── script.js
└── song.mp3
```

> Note: Modern browsers may block automatic audio playback until the user interacts with the page. The **Start Surprise** button starts the music through user interaction.

## 🎮 How the Website Works

### Step 1 — Welcome

The website opens with:

**Happy Birthday Brother ❤️**

and an animated background with stars and particles.

### Step 2 — Birthday Cake

Click:

**🎁 Start Surprise**

The birthday cake screen appears with glowing candles.

### Step 3 — Blow Candles

Click:

**🕯️ Blow Candles**

The flames disappear and a confetti animation starts.

### Step 4 — Birthday Celebration

The screen displays:

**HAPPY BIRTHDAY BROTHER ❤️**

with a glowing animated design.

### Step 5 — Personal Message

Click:

**💌 Read My Message**

A heartfelt message for your brother appears.

### Step 6 — Surprise Gift

Click:

**🎁 Open Your Surprise**

An animated gift box appears.

Tap the gift box to open it.

### Step 7 — Final Surprise

The final screen displays:

**HAPPY BIRTHDAY BROTHER ❤️**

with floating hearts, animations and a final birthday wish.

## 🌐 GitHub Pages Deployment

You can host this project for free using GitHub Pages.

1. Create a new **Public Repository** on GitHub.

2. Upload:

```text
index.html
style.css
script.js
song.mp3
README.md
```

3. Go to:

```text
Settings → Pages
```

4. Under **Build and deployment**, select:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

5. Click **Save**.

After deployment, your website will be available at:

```text
https://YOUR-USERNAME.github.io/birthday-brother/
```

Replace `YOUR-USERNAME` with your GitHub username.
